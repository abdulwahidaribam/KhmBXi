# KhmBXi

KhmBXi is an early-stage open-source project exploring a simpler way to deploy websites.

## Project status

This repository currently contains project and community documentation. It does not yet include application source, a runnable demo, a release, or verified installation and test commands. The project description and roadmap express intended direction; they are not claims about shipped functionality.

The runtime, architecture, supported deployment targets, and setup instructions will be documented after the source has been reviewed and verified.
